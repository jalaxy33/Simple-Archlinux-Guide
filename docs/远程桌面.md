# 远程桌面

- 共享桌面方案：可以用 `parsec` 或者 `sunshine+moonlight` 日月组合，推荐后者，性能更好。
- headless方案：`vnc`

## parsec

需要先注册账号。两台设备都安装 parsec，archlinux上通过 AUR 安装：

```sh
yay -S parsec-bin
```

之后在两台设备上开启软件，登录同一个账号，就可以远程串流了。
